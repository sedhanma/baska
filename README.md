# Garrafão

Site de basquete em um único arquivo (`index.html`). CSS e JavaScript ficam no próprio HTML. A única dependência externa é a fonte do Google Fonts.

Abra `index.html` no navegador, ou sirva a pasta raiz com qualquer servidor estático.

## GitHub Pages

O repositório está privado. No GitHub Free, o Pages publica só repositórios públicos. Para servir o site de graça:

1. Settings → General → Danger zone → **Change repository visibility** → Public
2. Settings → Pages
3. Source: **Deploy from a branch**
4. Branch: **main**, pasta **/** (root)
5. Save

O endereço fica `https://sedhanma.github.io/baska/`.
